# Anon — расширение браузера (прототип)

Chrome Manifest V3, Chrome 116+; совместимость с Edge проверяйте на своей версии.
Сборка и установка npm-зависимостей не нужны. Расширение работает по явному
действию пользователя, не перехватывает отправку сообщений и не меняет страницы.

## Установка и подключение

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение»
   и выберите каталог `anonymizer/browser-extension`.
3. Закрепите Anon в панели браузера, нажмите его значок.
4. В настройках боковой панели укажите адрес **сайта Next.js**, например
   `https://ваш-сервис.рф`, без `/api/v1/anonymize`. Для разработки допустим
   `http://localhost:3000`; HTTP для удалённых серверов запрещён.
5. Войдите на сайт и выпустите персональный API-ключ в `/account/developers`
   (нужна роль администратора или владельца). Вставьте ключ в настройки
   расширения и разрешите доступ к выбранному серверу. Не используйте
   внутренний `ANONYMIZER_BACKEND_KEY` Python-сервера.

Маскирование требует работающих Next.js и Python-бэкенда с настроенным доступом
и квотой. Один Python `server.py` не предоставляет публичный маршрут v1.
Настройки этапов обработки берутся с сервера; расширение их не ослабляет.

## Использование

- Выделите текст и выберите правой кнопкой «Маскировать выделенное в Anon».
  Либо нажмите `Alt+Shift+M`. Текст появится в панели, затем нажмите «Маскировать»:
  до этого действия сетевого запроса с текстом нет.
- Скопируйте результат кнопкой «Копировать» и вставьте в нужный сервис.
- Выделите ответ с плейсхолдерами, выберите «Восстановить выделенное в Anon»
  или нажмите `Alt+Shift+R`. Выберите нужную запись истории и нажмите
  «Восстановить». Результат показывается только в панели Anon.
- Можно вводить или вставлять текст непосредственно в панель. Горячие клавиши
  переназначаются в `chrome://extensions/shortcuts`.

Каждая операция создаёт **отдельную** таблицу соответствий: первые восемь слов
исходного текста (до 160 символов), дата, количество замен. Плейсхолдеры получают
случайный буквенный суффикс, например `[PERSON_ABCDEFGHIJKL_1]`, поэтому выбор
другой записи не подставляет чужие значения. Неизвестные плейсхолдеры остаются
без изменений с предупреждением. Общего словаря между разными сообщениями
диалога пока нет; ответ, объединяющий несколько операций, восстанавливайте
последовательно с соответствующими записями.

Ограничения прототипа: 100 000 символов на операцию, 50 записей, до 8 МБ данных
сессии. История не удаляется автоматически для освобождения места. Нет
вложений, автоматической замены выделения, плавающей кнопки и экспорта mapping.
На служебных страницах браузера и в некоторых iframe/редакторах извлечение
выделения недоступно — вставьте текст в панель вручную.

## Хранение и обработка

- API-ключ, таблицы, заголовки и результаты хранятся только в
  `chrome.storage.session`, без `local`, `sync`, аналитики и внешних скриптов.
  История и ключ теряются при перезапуске браузера, отключении, обновлении или
  перезагрузке расширения. После этого восстановление с этими таблицами
  недоступно. Перед важной работой учитывайте это ограничение прототипа.
- Первые восемь слов могут содержать персональные данные; они видны в истории.
  Кнопка очистки текста очищает поля панели, а удаление истории — таблицы.
- **Маскирование серверное**: исходный текст передаётся выбранному серверу Anon
  как `selection.txt` через существующий Bearer API v1, с его квотами, заданиями,
  правилами хранения и подключёнными NER/LLM/review. Нельзя обещать полностью
  локальную обработку или отсутствие хранения на сервере. Восстановление
  выполняется локально без HTTP-запроса.
- Доступ к серверу запрашивается отдельно при сохранении настроек. Постоянного
  чтения всех страниц нет: используется `activeTab` и выполнение небольшого
  скрипта чтения выделения по действию пользователя. API-ключ и таблицы не
  передаются скриптам страниц.
- Ввод оригинала в поле стороннего сайта уже делает его доступным этому сайту.
  Для подготовки сообщения до передачи сервису вводите оригинал в панель Anon.
  Расширение не гарантирует полноту обнаружения персональных данных.

Закрытие панели не отменяет задание на сервере. Опрос возобновляется при
следующем открытии; сервер может удалить результат по TTL (сейчас 10 минут
после завершения). Для остановки нажмите «Отменить», пока панель открыта.
Ошибка постановки запроса с таймаутом не гарантирует, что сервер его не принял;
повторная отправка может создать ещё одно задание и расход квоты.

## Проверки

Из этого каталога:

```powershell
npm.cmd test
node --check background.js
node --check panel.js
```

Тесты используют синтетические данные и поддельный HTTP API; реальные ключи,
платежи, документы и рабочая база не нужны.

Дополнительная проверка установленного расширения в настоящем браузере:

```powershell
node tests/browser-smoke.mjs 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
```

Она запускает браузер без окна с отдельным временным профилем и синтетическим
API, проверяет настройки, историю, маскирование, локальное восстановление без
сети, неизвестные плейсхолдеры, повторное открытие панели и очистку полей.
Разрешение подключения в этой проверке подменяется; настоящий диалог выдачи
разрешения и обработку на рабочем сервере нужно проверить вручную.

Ручная проверка с подключённым сервером: маскировать синтетический абзац,
восстановить его без сети, создать вторую запись с другим именем, проверить
неверный выбор таблицы, отмену задания, закрытие/открытие панели и очистку
сессии при перезагрузке расширения. Убедиться, что сайт назначения получает
только скопированный пользователем обработанный текст.
