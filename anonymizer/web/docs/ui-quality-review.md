# Проверка интерфейса — 3 ноября 2026

Проверены главная рабочая страница, приветственный экран, вход, регистрация,
тарифы, подписка, платежи, приглашение, правовая информация, оферта,
политика и страница 404. Проверка следует методике
[unslop — Damir Sokolovsky](https://heydamir.design/unslop), CC BY 4.0.

## Направление

- Продукт: обратимое маскирование документов с ключом восстановления.
- Характер: точный, спокойный, понятный.
- Материал: документ и рабочая панель; существующая палитра сохранена.
- Главный визуальный момент: выделение данных и их замена на маски.
- Фирменная деталь: плейсхолдеры в квадратных скобках.

## Что исправлено

- Демонстрация использует общий цикл 2,4 секунды: выделения по 300 мс,
  начала строк — 0 / 600 / 1200 мс, общий сброс — 2100 мс. Исходный текст
  и маска не накладываются. Пауза останавливает и выделение; при reduced motion
  показаны статические маски, неработающая кнопка паузы скрыта.
- Удалена ссылка «Узнать больше». Верхняя ссылка называется FAQ и доступна
  на узком экране. Карточка ключа больше не перекрывает паузу; исправлена
  компоновка точки в знаке логотипа.
- Три выбора файлов получили доступные с клавиатуры кнопки. Скрытое меню
  исключено из порядка фокуса через `inert`; при закрытии из панели фокус
  возвращается на кнопку открытия.
- Поля приглашений и словаря получили доступные имена. Ошибки входа,
  регистрации и приглашения объявляются через `role="alert"`; подсказки
  паролей связаны с полями.
- Длинные названия тарифов и строки платежей переносятся. В банковских
  реквизитах исправлена структура `dl`; кнопки копирования имеют высоту
  не менее 44px на устройствах с сенсорным вводом.
- На правовых страницах и 404 используется имя Anon.

## Удалённый лишний код

Удалены недостижимая гостевая ветка рабочего интерфейса и связанный импорт,
неиспользуемый параметр `onStart`, стили `scrollHint`, `sidebar-user`,
`payment-current`, старые ключевые кадры и повторные правила анимации.
Общие стили форм и правовых страниц сохранены: они используются несколькими
маршрутами. Дополнительных неиспользуемых переменных проверка TypeScript
с `noUnusedLocals` и `noUnusedParameters` не нашла.

## Проверки и ограничения

В настоящем браузере выполнены 26 сценариев: 13 страниц/состояний при ширинах
1280 и 390px. Проверены переполнение страницы, FAQ, пауза, временная шкала
анимации, закрытое меню, кнопки выбора файла и структура реквизитов.
Визуальный контроль первого экрана выполнен через agent-desktop.
Первоначальный сценарий FAQ был уточнён: теперь он ожидает обновления React
и раскрытия, вместо проверки после фиксированной задержки.

Все обращения к аккаунтам в браузерной проверке заменены синтетическим API;
записи заблокированы. Реальные вход, загрузка документов и платежи этим
прогоном не проверялись. Работа с локальной БД прекращена по просьбе владельца;
учётная запись для проверки не создавалась.

Проверка TypeScript с поиском неиспользуемых переменных, 10 изолированных
Node-тестов и `git diff --check` прошли. Производственная сборка Turbopack
завершилась успешно с изолированным `DATABASE_URL`, чтобы не обращаться к
локальной базе. При инициализации серверных модулей она выдала предупреждения
Prisma о недоступности этого подключения и установке PRAGMA; это не проверка
работоспособности БД.

## Следующий отдельный этап

Витрина тарифов и подписка используют графитовую палитру, а рабочая панель,
формы входа и правовые страницы — более раннюю синюю. Их полное объединение
лучше делать после выбора фирменного стиля, а не подменять аудит редизайном.
Глобальное скрытие полос прокрутки оставлено согласно существующему
намеренному оформлению проекта. Дробить большой рабочий компонент на новые
модули стоит отдельной задачей с проверками обработки документов: это не
безопасное удаление «лишнего» кода.
