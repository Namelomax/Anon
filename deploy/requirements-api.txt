# Зависимости для развёртывания «только API»: GLiNER и LLM живут на внешнем
# шлюзе (--ner remote), на хосте не остаётся ни моделей, ни torch.
#
#   pip install -r deploy/requirements-api.txt
#
# Отсюда НАМЕРЕННО убраны gliner, transformers, huggingface-hub и torch — они
# нужны только для --ner gliner. Установка ужимается с ~2.5 ГБ до десятков
# мегабайт, а процесс с ~2 ГБ RSS до ~150 МБ. На хосте с 3.8 ГиБ памяти это
# разница между «влезает» и «не влезает».
#
# Ядро анонимайзера (engine, detectors, spans, verify, chunking, glossary,
# mapping, review, llm, server) само по себе не импортирует ничего вне
# стандартной библиотеки, КРОМЕ одного исключения: словарь морфологии для
# детерминированного гейта размаскировки PERSON (detectors.py,
# ``is_person_word_droppable``). Этот гейт — единственная защита от того, что
# LLM-модель на review-стадии решит, будто редкая незнакомая фамилия («Вайгус»
# — измеренный в проде кейс утечки, PERSON 33 → 29) — обычное слово, и снимет
# с неё маску; без словаря гейт работает в fail-safe режиме и ОТКАЗЫВАЕТ любое
# снятие маски с PERSON (наблюдалось в проде: PERSON 33 → 44, гейт фактически
# слеп). pymorphy3 + словарь pymorphy3-dicts-ru — это чистый Python + данные
# (никаких torch/numpy), добавляют единицы МБ к установке и не тянут за собой
# NER/embedding-модели natasha (та тоже оборачивает pymorphy2, но пул её
# зависимостей велик — здесь она НЕ нужна, только гейт). Именно pymorphy3, а
# не pymorphy2: на Python 3.11+ (в т.ч. на 3.12.3, который стоит на боевом
# хосте) простое построение ``pymorphy2.MorphAnalyzer()`` падает с
# ``AttributeError: module 'inspect' has no attribute 'getargspec'`` — эта
# функция убрана из stdlib в 3.11, — то есть pymorphy2 там не работает вовсе,
# и гейт молча оставался бы в fail-safe режиме навсегда. pymorphy3 — тот же
# API и те же словари OpenCorpora, но поддерживаемый форк без этой поломки.
#
# Всё перечисленное ниже, кроме pymorphy3/pymorphy3-dicts-ru, нужно
# ИСКЛЮЧИТЕЛЬНО для чтения документов и импортируется лениво, внутри функций
# documents.py. Для конвейера на голом .txt не нужно вообще ничего, кроме
# самого словаря морфологии (импортируется лениво из detectors.py).

pymorphy3           # словарь морфологии для гейта размаскировки PERSON
pymorphy3-dicts-ru  # (см. пояснение выше) — редкая фамилия не должна утечь

python-docx        # .docx — чтение/запись с сохранением структуры
lxml               # .xml, .odt (и зависимость python-docx)
openpyxl           # .xlsx / .xlsm
xlrd>=2.0.1        # .xls  — старый Excel 97-2003
olefile            # .doc  — старый Word 97-2003, нативный разбор на Python
pypdf              # .pdf  — извлечение текстового слоя
